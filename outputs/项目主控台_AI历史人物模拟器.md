### 今天修复的几个硬问题

1. **API 调用失败**：python.org 版 Python 在 macOS 无根证书 → 自动挑系统证书包（`/etc/ssl/cert.pem`）。
2. **seed 更新不生效**：`figures.json` 一旦生成就不再同步 → 引入 `SEED_VERSION`，版本变了自动重建。
3. **多语言只翻顶栏**：`MutationObserver` 被自身写入触发形成自激循环 + 遍历无异常隔离 → WeakMap 存原文、差异写入、翻译时断开 observer、逐节点 try/catch。
4. **悬停提示与说明正文未翻**：`data-tip` 属性未纳入翻译；`/api/rubric` 文案不在词典 → 补齐。
5. **英文标签与得分条重叠**：标签列固定 84px 太窄 → 改 `minmax(96px,168px)`；侧栏画像改两行布局。
6. **含变量的句式漏翻**：`平均提示级数（N% 用过提示）`这类"中文+变量+中文"同节点 → 加句式模式。
